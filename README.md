# Wandr

## Overview 
An application that allows users to document their travels in the form of digital travel journals: each trip meals eaten and activities done, each rated, described and illustrated with a photo. 
The objective is to keep a structured and searchable memory of experiences, sortable by trip, category, rating or tag.

Main Features : 
  -  Trip Creation: name, dates, country/city, cover photo, status (upcoming / in progress / completed)
  -  Adding Memories within a trip, classified into two categories: Meals and Activities
  -  Photo, name, precise location, free description
  -  Multi-criteria rating (e.g.: taste / price / ambiance for a meal; interest / effort for an activity)
  -  Free tags (Favorite, To repeat, Disappointing, Too expensive...)
  -  Sorting and Filters: by trip, by category, by rating, by tag
  -  Map View: localization of memories on the trip map
  -  Statistics: top meals/activities across all trips, average rating by country, total budget
  - Dashboard: overview of all trips with their key indicators
